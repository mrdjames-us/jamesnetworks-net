# Shared Pages project: journal + consulting

One Cloudflare Pages project, two hosts.

| Host | What |
|------|------|
| **www.jamesnetworks.net** | Personal journal — David James, notes from Clinton, Missouri |
| **www.henrycountyconsulting.com** | Henry County Consulting — paid AI/workflow consulting |

Middleware in `functions/_middleware.js` picks the site from the `Host` header. Consulting files stay at the repo root. The journal lives in `journal/` (markdown in `journal/content/`, HTML generated by `journal/build.mjs`).

## Write a journal post

See `journal/README.md`. Short version:

```bash
# add journal/content/posts/YYYY-MM-DD-slug.md
node journal/build.mjs
.\deploy-demo.ps1
```

Demo preview:

- Consulting: https://jamesnetworks-net-demo.pages.dev/
- Journal: https://jamesnetworks-net-demo.pages.dev/?site=journal

## Deploy

```powershell
.\deploy-demo.ps1    # demo only
.\deploy-prod.ps1    # production (types PROD) — updates BOTH domains
```
