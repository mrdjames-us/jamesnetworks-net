# MSP prompts

Each `.md` file here is one card on `/msp/prompts/` plus a detail page.

## Add a prompt

1. Copy `_sample.md` to `short-name.md` (no leading underscore).
2. Fill `title` and `summary`. Optional: `tags`, `date`.
3. Put the prompt itself in the body (a fenced code block stays copy-friendly).
4. Rebuild: `node journal/build.mjs`
